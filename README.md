# 🌍 WanderLust – Full Stack Travel Listing Platform

WanderLust is a full-stack travel listing web application where users can explore, create, update, and manage travel destination listings. The application is built using Node.js, Express.js, MongoDB, and EJS following the MVC architecture.

---

## ✨ Features

- View all travel listings
- Add new travel listings
- Edit existing listings
- Delete listings
- View detailed information for each listing
- Add reviews for listings
- Responsive user interface

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/aditi968malviya/wanderlust-fullstack.git
```

2. Go to the project folder

```bash
cd wanderlust-fullstack
```

3. Install dependencies

```bash
npm install
```

4. Start MongoDB

Make sure MongoDB is running locally.

5. Start the application

```bash
node app.js
```

6. Open your browser

```
http://localhost:8080
```
